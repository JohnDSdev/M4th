# M4th

An offline-first Android mathematics learning app: complete lessons, randomized practice with immediate feedback, accessible mathematical input, lightweight mastery and review, and reusable declarative course content.

The first course covers all fifteen topics in Precalculus Unit 2: Exponential and Logarithmic Functions.

Built in native Java with a locally bundled HTML/JavaScript course engine and KaTeX mathematics rendering. CI builds and emulator-tests a debug APK. See the project source for implementation and limitations.
